# HTML2PPTX Troubleshooting

## Browser Launch Fails

Symptoms:

- `Timed out waiting for Chrome remote debugging`
- `Permission denied` from Chromium on macOS
- Keychain prompt appears

Fixes:

- Pass `--chrome /path/to/chrome`.
- Prefer Playwright Chromium if installed:
  `python -c "from playwright.sync_api import sync_playwright; p=sync_playwright().start(); print(p.chromium.executable_path); p.stop()"`
- The launcher already includes `--use-mock-keychain` and `--password-store=basic` to avoid macOS keychain prompts.

## Blank Charts

The DOM extractor patches ECharts to SVG renderer before chart init scripts run. It also attempts to rebuild already-initialized ECharts canvas instances with their existing `getOption()` data and an SVG renderer. If charts are still blank:

- Confirm the deck has `script[type="application/webdeck-chart-init"]` blocks.
- Confirm ECharts is available offline or embedded in the HTML.
- Open the intermediate `svg_output/NN_slide.svg` to see whether chart primitives exist.
- If the chart uses custom renderers, external images, maps, or unsupported extensions, use a screenshot fallback for that page.

## Missing Text

Common causes:

- Text is generated by CSS pseudo-elements (`::before`, `::after`).
- Text is inside external icon fonts or web fonts that did not load.
- The slide contains nested full HTML documents (`<!doctype html><html><head>...`) inside `.deck-stage`.

For nested full documents, preprocess the deck so each slide contains a normal fragment, not a complete HTML page.

## Wrong Borders or Black Text Boxes

Uniform four-side CSS borders on rounded boxes are emitted as one rounded rectangle with a stroke. Single-side or mixed CSS borders must still become separate SVG lines. If a deck shows heavy boxes:

- Inspect `svg_output/NN_slide.svg`.
- Check whether elements use `border-left`, `border-bottom`, or table cell borders.
- Uniform rounded boxes should appear as `<rect rx="..." stroke="...">`; mixed borders should appear as `<line>` primitives.

## Plain HTML Becomes Zero Slides

The wrapper auto-detects HTML without `.deck-slide` and wraps the body as one WebDeck-compatible 1280x720 slide. If the source is a long webpage, only the first viewport is captured.

Fixes:

- Convert the source into fixed 16:9 sections before export.
- Split long documents into multiple HTML files or WebDeck slides.
- Use `--keep-workdir` and inspect the generated `sources/*.html2pptx-wrapped.html` file if layout looks unexpected.

## Off-Slide Content

The extractor uses a 1280x720 viewport. Long webpages or `100vh` sections inside a slide may place content below the slide.

Fixes:

- Redesign the source page as a fixed 16:9 slide.
- Add a preprocessing step that scales the long page into the viewport.
- Split long pages into multiple slides.

## Case Study: Hermes-Style Nested Webpages

If a deck page contains a full document under `.deck-stage`, such as:

```html
<div class="deck-stage"><!DOCTYPE html><html><head>...</head><body>...</body></html></div>
```

conversion quality may drop sharply. Typical symptoms:

- A source page with tens of thousands of HTML characters becomes only a handful of PPTX shapes.
- Many generated shapes have `y` coordinates beyond the slide height.
- Only the title/subtitle survive, while cards and grids disappear.

Reason: the browser repairs invalid nested documents, and the extractor captures the visible 1280x720 viewport rather than the entire long page. Treat these pages as source authoring issues: convert them to fixed-size slide fragments before running `html2pptx`.

## Validating Editability

Use:

```bash
python - <<'PY'
from zipfile import ZipFile
from pathlib import Path
p = Path("output.pptx")
with ZipFile(p) as z:
    slides = [n for n in z.namelist() if n.startswith("ppt/slides/slide") and n.endswith(".xml")]
    sp = sum(z.read(n).count(b"<p:sp") for n in slides)
    pic = sum(z.read(n).count(b"<p:pic") for n in slides)
print("slides", len(slides), "editable shapes", sp, "pictures", pic)
PY
```

`pictures=0` usually means there are no full-slide image fallbacks.
