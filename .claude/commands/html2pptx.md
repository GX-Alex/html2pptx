# html2pptx

Convert an HTML/WebDeck slide deck to editable PPTX.

This command calls the same converter used by the `.claude/skills/html2pptx` project skill.

```bash
python skills/html2pptx/scripts/html2pptx.py "$ARGUMENTS"
```

Example:

```bash
python skills/html2pptx/scripts/html2pptx.py deck.html -o deck.pptx
```
